# Seething Sparrows

## Abstract
In this project, we will use object-oriented design to implement a homebrew version of the classic mobile game Angry Birds, which we call Seething Sparrows. Within the game, the user controls the trajectory of birds from a slingshot onto a pile of enemies (pigs) and blocks. Once all the pigs are destroyed in a level, the level is completed. The intention is to have multiple levels, each with a different design, which includes the organization and location of the blocks, the number of birds and pigs, and even the types of birds the user controls.

This will be implemented in pygame, where we will build a custom physics engine to handle collisions between the birds, pigs, and blocks. Class inheritance will be useful to classify each object, whereby a parent class will hold each of the Block, Pig, and Bird child classes, which will each contain their own variants as well. By organizing the game objects this way, we allow flexibility through polymorphism and easy level design. Ultimately, this project highlights how object-oriented patterns simplify tracking game states and support easy level scalability within this 2D video game environment.
